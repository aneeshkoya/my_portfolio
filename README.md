# Aneesh M. Koya Portfolio

A static personal portfolio customized from Aneesh M. Koya's CV.

## Included

- `index.html` - portfolio content with profile summary, skills, experience, projects, education, research, and contact sections
- `styles.css` - responsive visual design for the portfolio
- `assets/ai-research-hero.png` - generated hero visual for the AI research theme

## Publish on GitHub Pages

1. Create a GitHub repository for the site.
2. Push these files to the repository.
3. In GitHub, open `Settings` > `Pages`.
4. Set the source to the `main` branch and `/ (root)` folder.
5. Open the deployed GitHub Pages URL after the build completes.

## Notes

The CV listed LinkedIn, Google Scholar, Scopus, and OpenReview profiles without visible URLs in the extracted PDF text, so the portfolio names them without linking to guessed addresses.
