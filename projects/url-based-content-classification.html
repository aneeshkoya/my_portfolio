Case Study

URL-Based Content Classification

URL classification using DistilBERT and earlier BiLSTM-based approaches, enabling classification when full-page content was unavailable.

DistilBERTBiLSTMTransformersNLP

Problem

Full-page content is not always available, limiting contextual inventory coverage and downstream targeting decisions.

Approach

Modelled URL strings using earlier BiLSTM baselines and transformer-based DistilBERT classification to infer contextual categories from sparse signals.

Trade-offs

Used URL-only classification as a complementary signal rather than a replacement for full content understanding.
